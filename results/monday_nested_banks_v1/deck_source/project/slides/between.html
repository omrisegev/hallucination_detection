This is the most useful mechanistic finding: estimation error in the between-group stage is not what limits us. Even oracle group accuracies give the same AUC. The remaining gap to a supervised linear reference sits in which channels inside a group carry the signal, and no label-free within-group rule we tried (HEM, MoM-within, TCI) recovers it.
