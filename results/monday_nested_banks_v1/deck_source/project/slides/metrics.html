Four questions, four metrics, never averaged

MetricQuestion it answersNeeds a threshold?
Within-answer AUCAre error steps ranked above correct steps in the same answer?No: pure ranking
Top step is an errorIs the single most suspicious step wrong? (ProcessBench: is it the first error?)No: one step per answer
PRMScore (PRMBench)Mean of F1 on correct steps and F1 on error steps after flaggingYes: how many steps to flag
Official F1 (ProcessBench)First error found AND clean answers left unflaggedYes: includes the "no error" decision

Threshold-free metrics measure the score itself. Threshold metrics also measure the decision rule, which is our weakest component.

2 · Metrics

Keep the four apart throughout. AUC and top-step are about ranking; PRMScore and ProcessBench F1 add a decision about how many steps to flag and whether an answer is clean. Comparisons with a supervised PRM are fair only when threshold access is matched, so we always show an equal-budget version (one flag per answer) beside each method's own rule.
