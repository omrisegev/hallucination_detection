HEM: learned weights inside each group cost ProcessBench accuracy

Model

Each group g has its own binary latent state a_g, which depends on the true class Y: P(a_g | Y). Members vote given a_g: P(f_i | a_g) = e_i.

Member weight w_i = max(0, log(e₁(1 − e₀) / (e₀(1 − e₁)))); groups under 3 members get equal weights.

Origin

The dependent-classifier model of Jaffe et al. 2016, estimated by full EM: our implementation (cvf_v2, Step 457); no paper uses this exact estimator.

Estimate vs truth and outcome

Over channels (Step 450, 5 folds): prevalence error 0.144, ψ-MAE 0.110, η-MAE 0.072, Spearman 0.779; 0 of 5 folds pass the accuracy bar.

Within groups it is equivalent to MoM-within (0.7682 vs 0.7683 AUC).

ProcessBench: HEM_MOM 0.355 vs MEAN_MOM 0.366 top-step hit, about one point lost.

27 of 2,021 members receive weight 0 across the 72 original bank-cells.
