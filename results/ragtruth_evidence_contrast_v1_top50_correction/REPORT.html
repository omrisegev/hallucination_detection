Can spectral fusion improve evidence perturbation?

The development gate passed. The frozen corrected test scores show that Evidence-Contrast fusion beats the approximate GASP baseline, but DUFS-LIU does not beat IU-PCR. The feature construction worked; the registered graph mechanism did not.

0.703 EC-DUFS-LIU sentence AUROC · Δ vs GASP-top50 +0.031 · Δ vs EC-IU-PCR -0.001

Protocol correction: the original blind run used saved full-vocabulary entropy. This report uses the approved top-50-plus-tail entropy formula, corrected after the original test labels had already been opened. The formula was fixed by the plan rather than selected from labels, but this is not a new blinded confirmation.

How the experiment was protected

The answer text never changes. A small scorer reads it under several evidence conditions. Features and unsupervised scores are written and hashed before RAGTruth labels are loaded.

Data coverage

The no-context cohort contains all tasks. The complete leave-one-chunk-out (LOO) cohort contains QA and Data-to-Text only. Summary is never given invented LOO features.

How the methods differ

GASP-top50

Standardize four evidence-sensitivity measurements and negate their sum. No covariance model is fitted. JSD uses the saved top-50 union plus one tail bucket.

h = -Σ z(gap, JSD₀, max-drop, max-JSD)

EC-U-PCR

Estimate feature-to-grounding covariances from feature covariance under the additive uncorrelated-error model. Weak estimated regressors may be removed.

Cᵢⱼ ≈ ρᵢ + ρⱼ − g²

EC-DUFS-LIU

Learn label-free feature gates, build a sample graph, and penalize a fused score that changes sharply between graph neighbours.

wλ = U[Uᵀ(C + λR̄)U]⁻¹Uᵀρ̂

Primary result

AUROC is the probability that a randomly selected hallucinated sentence receives a higher suspicion score than a grounded sentence. AUPRC emphasizes precision on the rarer hallucinated class. Intervals resample complete source groups 1,000 times.

Where the result comes from

QA and Data-to-Text both improve over GASP-top50 at sentence level. DUFS-LIU does not improve over IU-PCR in either source family.

The loss is label-free. DUFS keeps an effective 13.40 of 14 features; 78.6% of gates are above 0.95 and 0.0% are below 0.05.

Confound checks

A confound is a nuisance variable that may explain a score without representing grounding. At sentence level, residualizing length, chunk count and context length changes AUROC from 0.703 to 0.689. At response level it changes from 0.748 to 0.647; this larger drop is a warning about response-level transfer.

Post-hoc old-method audit

The stored telemetry can reproduce the global 30-feature intrinsic mixed-v2 DUFS-LIU baseline exactly. This audit was added after test labels had opened, so it has a separate score hash and cannot change the registered decision. Its pooled response AUROC is misleading: it performs strongly on QA but falls below chance on Data-to-Text. Evidence-Contrast removes that catastrophic task failure.

Important limitations

  • GASP-top50 is not a faithful full-vocabulary GASP reproduction.
  • The scorer is Qwen2.5-1.5B, not necessarily the model that generated each published response.
  • RAGTruth annotations are incomplete; these are benchmark-label results, not absolute grounding accuracy.
  • Evidence removal also changes prompt length and token positions.
