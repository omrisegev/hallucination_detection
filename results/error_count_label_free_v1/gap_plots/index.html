1–2. היסטוגרמות: הצלחות מול כישלונות

ציון כל צעד בתוך התשובה שלו (answer-z). כחול = צעדים נכונים, כתום = צעדים שגויים. הצלחה = GAP סימן בדיוק את הצעדים השגויים.

3. בתוך תשובה אחת: הפער שנבחר מול שאר הפערים

משמאל: הצעדים ממוינים לפי ציון. מימין: הפער בין כל שני צעדים סמוכים. הבר השחור = הפער ש-GAP בחר; הקו הכתום = היכן החיתוך היה צריך להיות לפי מספר השגיאות האמיתי.
