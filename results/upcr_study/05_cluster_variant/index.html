What the variant changes

U-PCR turns 'which features should I trust?' into one equation per feature pair, assuming features fail independently. Ours do not: near-duplicates have correlations up to 0.996, and the model can only explain such a pair by inflating both features' scores. The variant keeps only the equations from pairs in different clusters, where the assumption still holds — Phase B2 measured those as fitting 2.03× better in 25/25 cells. Nothing else in the method changes, so a difference is attributable.
