How to read this

  • "Used to choose SUB5" are PRMBench and Socratic-PRMBench. SUB5, and most choices behind CHAIN and TELE_N16, were tuned on them, so wins there are in-sample.
  • Competitor numbers are copied from each paper. PRISM, CROP and the Hard2Verify row used Qwen2.5-Math-PRM-7B, so the same line is drawn for all four PRMs as a reference.
  • CROP's numbers use its own fixed threshold grid; ours use a quantile grid, which alone raises the PRM from 4.8% to 17.2% on PRMBench.
  • PRM800K's CROP line is the best row CROP reports there (a supervised token/format model). The paper's text gives no Trace+PRM value for it.
  • "Label-free rule" (GAP) chooses how many steps to flag per answer without labels. On CRV and PRM800K, where only 3 to 7% of steps are wrong, the PRM's own threshold beats every method under this rule.
  • Hard2Verify has 177 answers, DeltaBench 447 (the answers that fit in 4,096 tokens). All numbers are development data.
