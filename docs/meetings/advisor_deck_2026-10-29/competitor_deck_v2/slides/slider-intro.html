The paper · arXiv 2610.00571, ICLR 2026 workshop

SLIDER: find steps that only repeat what was said

What it does

Splits the information each step adds about the final answer into new, repeated and combined parts (Step-RRI)

Inputs

MiniLM sentence embeddings, plus up to 50 GPT-4o-mini answer variants per problem

Labels

Score is training-free; the threshold is a classifier fitted on labelled data

Benchmark

Only PRMBench’s redundancy class (about 750 answers). Metric: accuracy

Code

None released; split and class balance not stated

A redundant step is not wrong, it adds nothing. A correctness score such as a PRM is not built to catch it.

Because the protocol is under-specified, this comparison is approximate. About 87% of steps in this class are not redundant, so plain accuracy rewards never flagging (86.8%). We report balanced accuracy.
