SLIDER and ARES: approximate comparisons

SLIDER · redundant steps

76–77 vs 61.9

TELE16 balanced accuracy vs SLIDER’s published accuracy. The PRMs alone get 53–66.

Caveat: one class of one benchmark, protocol not fully stated, no code.

ARES · entailment by an LLM

.749 vs .736

In its own appendix the Qwen PRM alone beats ARES on PRMBench. Main result: macro-F1 .640.

Caveat: unstated subset, threshold tuned by CV, many LLM calls per step.

SLIDER: arXiv 2610.00571. ARES: arXiv 2507.12948, Table 1 and Table A7.

SLIDER: a trivial classifier that says "not redundant" gets 86.8% plain accuracy, so we report balanced accuracy. ARES numbers are not table-comparable with ours, because the subset and threshold differ. The useful point: a training-free method on PRMBench that does not beat the PRM.
