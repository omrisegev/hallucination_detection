# Complete plot and document index

This index makes the existing work reusable without forcing every figure into the email. The three summary figures are embedded in the letter; the detailed reports below preserve the full experimental record. Status labels matter:

- **Frozen/certified**: appropriate for the main advisor narrative.
- **Development/mechanism**: useful for explaining why the research direction changed.
- **Exploratory/not promoted**: informative, but not a claimed result.
