## Summary

APORIA studies 150 stochastic responses to the same prompt in sentence-embedding
space. Correct responses are modestly more cohesive in the original space. Operational
separation comes from a correctness-labelled, prompt-specific Fisher direction, after
which APORIA-LP propagates labels by comparing Wasserstein distance distributions.

The paper contributes a genuinely new observation source relative to our single-trace
matrix: semantic geometry across alternative generations. It does not provide a
label-free deployable router: its strong classifier uses labels within the same prompt,
and learned directions barely transfer across prompts.

## Geometry, supervision, and access contract

- **Geometric object:** SBERT embeddings of completed response samples, not hidden
  states or probability trajectories.
- **Actual geometry:** pairwise Euclidean-distance distributions and a supervised
  Fisher projection. It does not estimate a manifold, density ridge, or tangent bundle.
- **Supervision:** Claude 4.5 Sonnet labels all responses; APORIA-LP uses labels from
  both classes inside each model-prompt pair.
- **Sampling:** 150 generations per prompt in the main dataset. About 30–50 labelled
  sibling responses are needed to approach the reported saturation regime.
- **Access:** black-box target model plus an external sentence encoder and judge.
- **Deployment:** retrospective completed-response classification; not causal/online.
- **Target:** factual correctness of time-sensitive short answers.

## Datasets & models used

- SOCRATES-300K: 100 event templates, years 2020 and 2022, ten base models from
  7B to 32B, and 150 responses per model-prompt pair.
- 300,000 raw responses; 231,473 remain after uncertainty and class-support filtering.
- Generation uses temperature 1.0, top-p 0.9, top-k 50, and up to 512 tokens.
- A CoQA bridge uses 199 prompts, 150 responses per prompt, and ROUGE-L-based labels.
- Sentence encoders include MiniLM L6/L12, base-v2, and mpnet-base-v2.

## Methods it compared itself against

SelfCheckGPT, Semantic Entropy, and an INSIDE-labelled proxy that substitutes SBERT
for the hidden states required by actual INSIDE. The paper explicitly notes that these
baselines solve a different problem from within-prompt label propagation. It also tests
linear regression, SVM, PCA, UMAP, random projections, and alternate encoders.

## Experiments — methodology & scores

The main APORIA-LP table averages 20 stratified response-level splits per prompt using
two thirds of sibling responses for training and one third for testing.

| Setup | Metric | Score | Notes |
|---|---|---:|---|
| Original SBERT space | inter/intra distance ratio | 1.13 | Weak raw separation |
| Fisher space | inter/intra distance ratio | 7.26 | Direction is label-supervised |
| APORIA-LP main | Accuracy / F1 | 87.2 / 90.7 | Prompt-local response split |
| 30 labelled siblings | Accuracy / F1 | 83.7 / 87.9 | Still prompt-local |
| 100 labelled siblings | Accuracy / F1 | 87.0 / 90.5 | Diminishing returns |
| CoQA bridge | Accuracy / F1 | 98.1 / 97.1 | ROUGE-L label contract |
| SelfCheckGPT | F1 | 89.8 | Different task/protocol |
| Semantic Entropy | F1 | 86.3 | Different task/protocol |
| Direct LR on SBERT | F1 | 91.1 | Simpler supervised control |
| LR after Fisher | F1 | 91.4 | Exceeds APORIA-Wasserstein 90.5 |

## Calibration, leakage, and failure cases

- The split is between responses to the same prompt, so the result does not establish
  generalization to a new prompt.
- Fisher directions are strongly prompt-specific: mean cosine 0.058 across prompts
  within a model, 0.145 across models for a prompt, and 0.055 jointly.
- Prompts lacking at least five examples of each class are removed; average hallucination
  prevalence is 80.9%. This label-conditioned selection excludes near-always-correct and
  near-always-wrong prompts and makes F1 easier to misread.
- Claude labels agree with the 1,000-row human audit only 87.9%; most judge disputes
  are false hallucination calls.
- At small N, the structural tests are usually not significant; simple supervised LR
  matches or exceeds the Wasserstein propagator.
- The data and code are linked through Zenodo, `emarich/Socrates-300K`, and
  `eOnofri04/APORIA`.

## Connection to our pipeline

A label-free APORIA-inspired context could be

\[
c_i=\operatorname{median}_{k<\ell}d(e_{ik},e_{i\ell}),
\qquad
d_{ik}=d(e_{ik},\operatorname{medoid}\{e_{i1:K}\}),
\]

where \(e_{ik}\) are sibling-response embeddings. This is genuinely outside the
single-generation \(P(X)\), but coherent repeated hallucinations remain a direct failure
world. Before any IU residual or router, it must beat simple answer agreement,
Self-Consistency, Semantic Entropy, and response length in a held-prompt premise test.

The published FDA/APORIA-LP classifier cannot be transferred to a new prompt without
prompt-local labels. It has no Localization or Early output. Existing local K=10 files
are Git-LFS pointers in this workspace, so a faithful existing-cache premise test is not
currently runnable without retrieving response artifacts and computing embeddings.

## Recommendation

**Possible future multi-pass Global premise test, not a current IU candidate.** Its
priority is below A6/PTNI and it must remain a separate sampling-cost tier. Do not cite
APORIA-LP as label-free geometry or as evidence for a single-pass router.
