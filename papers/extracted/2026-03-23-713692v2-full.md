Manifold geometry underlies a unified code for category and category-independent
features
Lorenzo Tiberi1 and Haim Sompolinsky1, 2
1Center for Brain Science, Harvard University, Cambridge, MA 02138
2Edmond and Lily Safra Center for Brain Sciences, Hebrew University, Jerusalem 9190401, Israel
In everyday vision, animals routinely extract from the same visual stimulus both object identity
and continuous identity-independent variables such as position and size. It has been shown that
linear decoding performance of both kinds of information increases along the ventral stream, sug-
gesting that inferior temporal cortex may be implementing a joint code for object category and
category-independent features. A central open question is whether such a code can indeed exist
within a single representation and, if so, what geometric properties enable it. Here, we show that
convolutional neural networks can develop such a code. We then derive a theory of regression on
category manifolds, identifying the key manifold-geometry measures that enable accurate readout of
category-independent features, and showing how they can be optimized while preserving manifold
properties known to support classification performance. We further characterize how common ex-
perimental constraints, such as subsampling neural units and using a limited number of categories,
affect the empirical estimation of regression performance. Our findings thus provide a principled
understanding of the geometry underlying joint codes and yield testable predictions for future neural
recordings probing the joint-code hypothesis in the ventral stream.
I.
INTRODUCTION
Natural intelligence often relies on extracting multi-
ple kinds of information from the same sensory stimu-
lus. In everyday vision, for example, animals routinely
extract both object identity and continuous, identity-
independent attributes such as position and size from the
same visual stimulus. A central question in neuroscience
is how the brain implements this ability.
Neural recordings in higher-order areas,
such as
macaque prefrontal cortex, anterior cingulate cortex, and
hippocampus [1, 2], show that multiple task-relevant vari-
ables can be decoded from the same population activ-
ity using simple (often linear) readouts.
This has led
to the hypothesis that a single high-level population
code can jointly encode multiple stimulus variables in
a linearly accessible form, raising the question of which
representational principles make such multi-variable en-
coding possible [3].
Existing theoretical accounts have
mainly addressed highly controlled regimes with low-
dimensional stimulus spaces and task variables [1, 2, 4–7],
leaving open the question of how multi-variable decod-
ability is achieved in regimes with many stimulus cat-
egories and high-dimensional within-category variability
spanning both category-specific latent factors and multi-
ple category-invariant features.
A natural setting to study this regime is vision, where
single-object images within a category can vary widely
across a range of category-preserving transformations.
Indeed, it has long been suggested that neural represen-
tations in primate higher-order visual areas encode not
only object category, but also category-independent fea-
tures [8–10], including object size [11, 12], texture and
material properties [13–15], shape properties [16, 17],
and facial properties [18, 19]. A seminal study [20] sys-
tematically tested the hypothesis of a joint population
code by showing that, along the macaque ventral stream
(V1→V4→inferior temporal cortex, IT), the linear de-
codability of object category and the linear regressibil-
ity of category-independent features, such as object po-
sition, size, and pose within the image, both increase.
Yet, despite these improvements along the visual hier-
archy, our analysis shows that even in IT cortex the
absolute regression performance as estimated from the
macaque recordings remains limited, raising the question
of whether this reflects experimental limitations—such
as population subsampling and limited image sets—or
instead a genuine constraint on how ventral-stream pop-
ulations can jointly encode object category and category-
independent features.
To address this question, convolutional neural networks
(CNNs) provide a useful testbed because they align well
with ventral-stream neural responses [21, 22] and can be
systematically investigated without the experimental lim-
itations of neural recordings. Recent work [23] suggested
that CNNs can indeed be jointly optimized for object
classification and regression of category-independent fea-
tures, indicating that a joint population code may at least
be possible in artificial systems. Here we address the fol-
lowing fundamental question: What properties of a pop-
ulation representation enable effective joint encoding of
category and category-independent information?
Identifying these distinctive properties requires a the-
oretical framework that relates linear classification and
linear regression performance to properties of neural rep-
resentations. For object classification, such a framework
already exists in terms of object manifolds, defined as
the set of population responses elicited by images from
the same category. Theoretical work relates aspects of
manifold geometry, such as radius and dimensionality,

across categories. We then identify the across-category
differences in manifold geometry that contribute to this
gap. We further investigate how this regression-relevant
manifold geometry can coexist with the manifold geom-
etry that supports linear object classification.
Finally,
we use this framework to identify signatures that distin-
guish a true joint code from a category-only code and
to quantify how common experimental constraints (lim-
ited categories and neural-unit subsampling) can obscure
those signatures.

II.
RESULTS
1.
Linear decoding framework
To assess how well neural representations encode both
an image’s object category and features that vary inde-
pendently of category (“category-independent” features),
we adopt the linear-decoding framework of [20] (Fig. 1).
We consider image datasets consisting of single-object
images labeled by category and by four continuous
bounding-box parameters describing object position and
size: center coordinates Ch, Cv and side lengths Lh, Lv
along the image’s horizontal (h) and vertical (v) axes
(Fig. 1a).
For each image, an N-dimensional neural representa-
tion vector is extracted from the activations of neurons
in the brain visual hierarchy or from the activations of a
CNN that mimics this hierarchy (Fig. 1b).
Finally, we evaluate the performance of linear decoders
in extracting category and category-independent infor-
mation from these representations, treating it as a proxy
for the decoding performance achieved by hypothetical
downstream neurons (Fig. 1c). For category, we train
one-vs-rest classifiers and evaluate their balanced classifi-
cation accuracy, averaged across category. For the bound-
ing box parameters, we train one linear regressor per pa-
rameter and evaluate it by normalized mean squared error
(nMSE), i.e., MSE divided by the parameter variance. All
decoding metrics are cross-validated over multiple train–
test splits.
2.
One code supports both classification and regression
We have applied this decoding framework to the pub-
licly available dataset of macaque recordings [34] stud-
ied in [20], reproducing their qualitative results (see SI):
decoding performance of both category and category-
independent features improves along the visual hierarchy.
However, we also find that absolute regression perfor-
mance remains limited: root nMSE remains above 0.5,
meaning that the root-mean-square prediction error is
still larger than half the across-image standard deviation
of the decoded feature.
To investigate what it takes to accurately perform both
categorization and regression tasks we apply the above
decoding framework to CNNs trained on a newly con-
structed large-scale dataset of single-object images with
category and bounding-box annotations (Fig. 1a). Im-
ages span many object categories (265) as well as many
images per category (20,000 per category:
10,000 for
training the CNN and 10,000 for generating neural rep-
resentations and evaluating linear decoders). The large
number of images and categories serves several purposes:
it enables effective training, a more precise statistical
characterization of neural representations, and it places
us in a regime closer to the limit of infinite number of
categories, which is valuable for testing theoretical pre-
dictions and serves as a clean baseline from which we
can later introduce controlled category subsampling. Im-
ages were generated with a multi-stage pipeline that uses
diffusion models [27, 31] to produce photorealistic single-
object images with a controlled distribution of bounding-
box parameters (Fig. 2; Online Methods).
On this dataset,
we fine-tuned an ImageNet-1k–
pretrained ResNet-50 (Fig. 3a), a state-of-the-art CNN
with good alignment to ventral stream responses [22]. We
treated the final feature layer as the shared representation
and attached two types of readout: (i) the standard lin-
ear classification head for predicting object category, and
(ii) four additional linear regression heads, each predict-
ing one bounding-box parameter (Ch, Cv, Lh, Lv). The
network was optimized end-to-end using stochastic gra-
dient descent on a combined loss: cross-entropy loss on
the classification head and Smooth L1 loss on each regres-
sion head (Online Methods). In addition to this model,
which we call network CR, we also trained the same ar-
chitecture exclusively on the classification task (network
C) and exclusively on the regression task (network R).

3.
Theory
What properties of the population code of network CR,
or of any population code in general, allow this opti-
mal performance in both classification and regression of
category-independent features? For classification, theo-
ries already exist that relate neural representation ge-
ometry to proxy measures of linear classification perfor-
mance, such as storage capacity [24], or few-shot learn-
ing accuracy [25]. Such theories are formulated within
the framework of object manifolds, defined as the collec-
tion of all neural representations of images belonging to
the same category (Fig.
4a). It has been shown that
along the hierarchy of both classification-trained CNNs
[26] and the ventral visual stream [25], such object man-
ifolds change their geometric properties, such as their di-
mensionality, radius, and centroid separation, so as to
become more and more disentangled, thereby improving
linear classification performance (Fig.
4a).
In a sys-
tem optimized also for regression, one could imagine a
similar scenario whereby, along the visual hierarchy, the
encoding of category-independent features becomes both
more linear within each manifold and more consistently
aligned across manifolds, such that it can be regressed ac-
curately by a single category-independent regressor (Fig.
4a). Unlike for classification, however, a theory identify-
ing and linking the relevant manifold geometry to linear
regression performance is currently lacking. We now de-
velop such a theory.
We begin by distinguishing two additive contributions,
of very different nature, that determine linear regression
performance for category-independent features (Fig. 4b-
c). Let E denote the test MSE obtained when linearly
regressing a given category-independent feature with a
single category-independent readout. We decompose it

4.
Manifold geometry reveals optimization strategy
In comparing network C to CR, we have shown how
the latter optimizes the manifold geometry relevant for
regression. But how is this optimization achieved while
preserving the same classification accuracy achieved by
network C? Our theory illuminates how this is possi-
ble: because regression-relevant geometry is mostly re-
lated to a specific direction within the manifold—the
feature-encoding direction—rather than the manifold as
a whole, it can be optimized with only marginal effects on
classification-relevant geometry such as manifold radius,
dimensionality and centroid separation.
We begin illustrating this by considering manifold
shapes,
which are directly related to classification-
relevant geometry such as manifold radius and dimen-
sionality [24, 25]. One example of a regression-relevant
measure whose optimization could affect manifold shape
is SNR. However, note that SNR can be increased via
two complementary strategies (Fig. 6a): (i) increasing
variance along the feature-encoding direction (and/or re-
ducing variance in directions orthogonal to it), thereby
reshaping the manifold; or (ii) re-encoding the feature
along more dominant principal-component (PC) direc-
tions, thereby increasing variance along the encoding
direction without affecting manifold shape.
We find
that network CR implements strategy (ii) almost ex-
clusively, thereby preserving the manifold shapes found
in the classification-optimized network C: manifold PC
spectra—used here as an estimate of manifold shapes—
are essentially unchanged relative to network C (Fig.
6b), while the overlap of the local feature-encoding di-
rection with the top PCs is substantially increased (Fig.
6c).
Similarly to manifold shapes, we also find that manifold
centroids—the other key geometric property relevant for
classification performance—show only modest changes in
norm and relative distance compared to network C (see
SI).
Beyond shape and centroid position, manifolds also
have an orientation.
We therefore consider alignment
between manifolds, which we quantify by an alignment
matrix A whose entry Aµν ∈[0, 1] is large when man-
ifolds µ and ν are aligned, i.e., their axes of variabil-
ity (PCs) point in similar directions and carry compa-
rable variance (see Fig. 6 caption for the formal defi-
nition). We have discussed how regression optimization
increases a form of direction-specific alignment, namely
the alignment a of the local feature-encoding directions.
Its effect on the overall manifold alignment A is, how-
ever, nontrivial, because a could be increased via two
complementary strategies (Fig.
6d): (1) rotating (in
the sense of re-encoding) the feature-encoding direction
within each manifold, without changing manifold orien-
tation and thus global manifold alignment; or (2) rotat-
ing the manifolds themselves while keeping the feature-
encoding direction fixed relative to their associated mani-
fold, thereby increasing global manifold alignment. While
we have observed a mechanism compatible with option
(1) in our analysis of manifold shapes (Fig.
6c), we
find that network CR partly implements also option (2),
as reflected by a clear, though modest, increase in the
average entry of A compared to network C (Fig.
6e).
Interestingly, while in network C the alignment matrix
A exhibits a block structure that mirrors the semantic
organization of categories, in network CR this structure
is largely obscured by the overall increase of alignment
across all categories (Fig. 6f).
More generally, these results show that regression op-
timization can leave only a subtle signature on coarse
measures of manifold geometry, such as manifold shape,
centroid position, and mutual alignment. This helps ex-
plain why networks C and CR exhibit highly similar rep-
resentations under widely used similarity measures such
as centered kernel alignment [35] (CKA; ∼0.95, see SI),
as well as similar alignment scores with neural data (see
SI), and may likewise account for analogous results re-
ported previously [23]. Our results therefore highlight the
importance of finer geometric measures—such as those
identified by our theory—that can distinguish a true joint
code even when coarser representational-similarity mea-
sures cannot.

To understand how the linear encoding of category

sual hierarchy, we next examine decoding performance

Experimental

performance, as estimated from current recordings, re-

on CNNs show, however, that improvement in regression
performance along the hierarchy is not by itself diagnostic
of a joint population code, since it occurs even in a net-
work that performs well only on classification (network
C). In network C, moreover, this improvement is con-
fined to the local error, while the local-global gap remains
high across layers, resulting in poor global regression per-
formance. By contrast, changes in the local-global gap
across layers appear more discriminative of a joint code:
in network CR, the gap is reduced by orders of magnitude
in the final layers.
Another interesting observation is that, in network CR,
regression performance improves sharply only in the final
layers, concurrently with a sharp rise in classification ac-
curacy. One possible explanation is that estimating an
object’s bounding box depends on first recognizing the
object, tightly linking regression performance to classifi-
cation accuracy. This may also help explain the across-
layer improvements in regression performance observed
in network C despite the absence of explicit regression
optimization, although other explanations are possible
[36], and a thorough investigation of them lies beyond
the scope of the present work.

III.
DISCUSSION
In this work, we addressed the question of what proper-
ties of a population code enable an effective joint encod-
ing of object category and category-independent features.
Using ventral-stream–like CNNs [22], we first showed that
such a joint code is possible: a CNN can be trained so
that the same feature-layer representation supports ac-
curate linear readout of both category and bounding-box
parameters. We established this on a large-scale single-
object image dataset developed for this study, featuring
photo-realistic images with controlled bounding-box dis-
tributions. We then developed a theory within the frame-
work of category manifolds [24, 25] to understand which
manifold properties enable not only linear separability
of categories, but also regression of category-independent
features.
While
previous
manifold-based
theories
linked
category-manifold
geometry
to
classification
perfor-
mance [24, 25, 37], here we extended that framework
to
provide
an
analogous
account
for
regression
of
category-independent features.
Central to our theoret-
ical framework is a decomposition of global regression
error into a local error, which quantifies how well a
feature is linearly encoded within individual category
manifolds,
and
a
local-global
gap,
which
captures
whether this encoding is organized consistently enough
across manifolds to support accurate readout by a single
category-independent regressor.
This decomposition
proves essential for characterizing a joint code. In our
empirical results, joint-code representations exhibit a
strongly suppressed local-global gap, reduced by orders
of magnitude relative to a population code that performs
well only on object classification. By contrast, differences

Notably, a small local-global gap can emerge
even when a network is trained only for classification
and category-specific regression, without the additional
constraint of a shared category-independent regressor.
Experimental studies probing the joint-code hypothe-
sis in the brain have focused on improvements in global
regression performance across the visual hierarchy [20],
although this performance, as estimated from current
recordings, remains limited even in IT. Here we show that
a similar improvement across layers can be seen even in
networks optimized only for classification. However, this
improvement is limited to the local error, while the local-
global gap remains high, resulting in poor overall perfor-
mance. Whether the limited regression performance cur-
rently estimated in IT reflects experimental constraints,
or instead the absence of joint-code properties such as
a suppressed local-global gap, is hard to judge from the
present experimental data.
To elucidate this, we have
characterized how experimental constraints affect the es-
timation of regression performance.
In particular, we
showed that subsampling neural units causes the esti-
mated local-global gap to increase sharply and, below
∼200 units, to reach similar values in networks with and
without a suppressed local-global gap, making the two
difficult to distinguish. This suggests that future experi-
ments may require larger-scale recordings to estimate the
local-global gap reliably.
We also considered the issue of finite number of cate-
gories, denoted here by P, in experimental setups. Pre-
vious manifold theories of classification [24, 37] focused
on the regime of a finite number of categories per neu-
ron, namely a fixed ratio of α = P/N where N is the
number of neurons used for the readout, or on tasks in-
volving a small number of categories, such as few-shot
generalization of object categories [25]. In contrast, for
a representation to support global regression of category-
independent features, it must be able to do so for images
associated with any category from the same statistical
ensemble, hence the relevant limit is P →∞for large
but fixed N. Indeed our theory predicts that the local-
global gap can be strongly underestimated in the finite-P
regime. Remarkably, the theory shows how to extrapolate
results from finite P to the large P limit (cf. Fig. 8a).
In this sense, our work goes beyond previous empirical
analyses of the local-global gap in pairs of manifolds [38],
by providing the first theoretical account of this gap in
terms of interpretable manifold-geometric measures, and
by formulating it in the P →∞regime most relevant
for cross-category generalization, while at the same time
yielding accurate finite-P corrections.
By idetifying the manifold-geometry measures predic-
tive of the local-global error gap, our theory allows to ex-
plain how these measures can be optimized alongside the
manifold geometry relevant to classification performance,
thereby implementing an effective joint code. This ques-
tion can be addressed here because our theory of regres-
sion is formulated in the language of category manifolds,
and therefore in the same framework used to study clas-
sification [24, 25, 37], unlike a recent theory of manifold
regression [39], in which manifolds are defined by dis-
cretized values of the regressed feature rather than by
category. Specifically, we find that regression-relevant ge-
ometry is mostly related to a specific direction within the
manifold—the feature-encoding direction—rather than
the manifold as a whole, and can therefore be optimized
with marginal effects on classification-relevant geometry
such as manifold radius, dimensionality, and centroid sep-
aration.
More generally, this implies that regression optimiza-
tion can leave only subtle signatures on coarse manifold-
geometry measures.
This helps explain why CNNs
trained only for classification and CNNs trained jointly
for classification and regression exhibit highly similar rep-
resentations under widely used similarity measures such
as CKA, as well as similar alignment scores with neural
data, and may likewise account for analogous results re-
ported previously [23]. Our results therefore highlight the
importance of finer geometric measures—such as those
identified by our theory—that can distinguish a true joint
code even when coarser representational-similarity mea-
sures cannot.
An open question is whether this picture persists
when representations must encode many more category-
independent variables.
At present, large-scale datasets
for studying the joint-code hypothesis [23], including
ours, contain annotations for only a few such variables,
making the development of richer datasets an important
challenge for future work.
Constructing such datasets
may draw on prior work that parameterized additional
visual features, including texture [14], material proper-
ties [13], shape [16], and facial properties [19, 40]. Alter-
natively, relevant features could be defined as stimulus
dimensions that maximize neural responses [41–43].
Several directions remain open for characterizing joint
codes in artificial networks. Here we focused on CNNs as
ventral-stream models [21–23], and on supervised train-
ing to compare representations explicitly optimized for
a joint code with those optimized only for classification.
An important next step is to ask whether joint codes also
emerge under self-supervised training [44–50], and how
different training augmentations may preserve or degrade
linear access to category-independent variables [51–53].
We also did not consider state-of-the-art object detec-
tion networks [54–59], because our goal was to study di-
rect linear readout from a single shared representation
rather than the more elaborate decoding pipelines used
in these systems. Among current detectors, DETR [59]
is arguably closest to implementing a joint population
code, since both category and bounding-box information
are read out from a common representation space, albeit
nonlinearly for bounding-box features, making it a natu-
ral target for future study.

Another recently introduced large-scale dataset for

Relative

dataset gains images with photorealistic appearance and
contextually relevant backgrounds, as they are generated
by diffusion models trained on natural-image statistics.
The two datasets therefore occupy complementary points
along the trade-off between controllability and realism.
Images in our dataset were generated using a multi-
stage pipeline that combines text-to-image generation
(Stable Diffusion XL, SDXL [27, 28]), object detection
(CerberusDet [30]), and image outpainting (Stable Diffu-
sion v1.5, SD1.5 [31–33]) to produce single-object images
with controlled object placement and controlled distribu-
tion of bounding-box coordinates. The pipeline to gen-
erate one image in our dataset consists of the following
three steps (cf. Fig. 2a).
Step 1:
Object generation.
We first generate a
“seed” image of a single object in the desired category
using Stable Diffusion XL. The goal of this step is sim-
ply to obtain a clear, unobstructed, single-instance de-
piction of the target object in a contextually appropriate
scene, without yet enforcing any control over object po-
sition or scale (i.e., control over the object’s bounding-
box parameters).
To make large-scale generation fea-
sible, we use SDXL-Lightning weights (model release
identifier: ByteDance/SDXL-Lightning) with the SDXL
base checkpoint (stabilityai/stable-diffusion-xl-base-1.0),
enabling generation in only 4 denoising steps. This al-
lowed us to synthesize the full dataset within a few days
on a 10×A100 GPU cluster. For a given category named
<category>, we use the following prompt: "A full-body,
photorealistic shot of a single <category>. The <cate-
gory> is the clear main subject, fully in the scene, and
unobstructed. The background is detailed, contextually
appropriate, but does not distract.".
We also use the
negative prompt: “clutter, multiple objects, occlusion,
low quality, blurry, distorted, unrealistic, extra limbs,
cropped, artifacts, persons, people, humans, mannequin”.
Step 2: Object placement. The goal of this step is
to enforce controlled object location and size by mapping
the seed image from step 1 onto a new canvas so that the
main object occupies a newly sampled bounding box. We
first obtain the object’s bounding box in the seed image
using CerberusDet, and treat this detected box as the ob-
ject’s initial bounding box. If CerberusDet does not de-
tect any instance of the object, we discard the seed image
and return to step 1. We then sample a target bounding
box on a fixed 512×512 canvas as follows. First, we sam-
ple a target maximum side length Lmax ∼Unif [200, 500]
(in pixel units) and isotropically rescale the seed image
such that the detected bounding-box’s maximum side
length matches the newly sampled one, that is we en-
sure max (Lh, Lv) = Lmax.
Next, conditioned on the
resulting (Lh, Lv), we sample the target bounding-box
center uniformly over all centers that would keep the
box inside the canvas: Ch ∼Unif [Lh/2, 512 −Lh/2] and
Cv ∼Unif [Lv/2, 512 −Lv/2]. In sum, object size (via
Lmax) is sampled uniformly over a prescribed range, and
object position is sampled uniformly conditional on size,
subject to the newly sampled bounding-box staying fully
within the image. To realize this target bounding-box, we
paste the rescaled seed image onto a blank 512×512 can-
vas so that the object bounding-box matches the target
one. Some regions of the canvas will remain uncovered
by the rescaled images, and are filled in Step 3 via out-
painting.
Step 3: Outpainting. The goal of this step is to fill
in the uncovered regions introduced in Step 2, produc-
ing a natural-looking full 512×512 image while preserving
the placed object and its newly sampled bounding box.
We achieve this by outpainting the uncovered regions us-
ing an outpainting variant of SD1.5. Starting from the
512×512 canvas produced in Step 2, we construct an out-
painting mask that marks the uncovered regions. To re-
duce visible seams at the boundary between original and
synthesized content, we blur the mask edges with a Gaus-
sian blur. Before outpainting, we initialize the undefined
regions with reflection padding to provide the generative
model with plausible color and texture statistics and re-
duce sharp discontinuities at the boundary between the
pasted seed image and the area to be synthesized. Techni-
cally, we fill each blank side by repeatedly tiling a mirror-
reflected strip of pixels taken only from the portion of the
seed image between the pasted-image border and the ob-
ject’s bounding-box edge (never from inside the bounding
box), so that the object itself is not reflected—avoiding
to encourage the outpainting model to generate addi-
tional instances of the object. We finally outpaint the
masked regions using SD1.5 inpainting (stable-diffusion-
v1-5/stable-diffusion-inpainting) with an LCM scheduler
and the latent-consistency/lcm-lora-sdv1-5 LoRA, using
4 denoising steps, guidance scale 0, and strength 0.95.
The outpainting prompt is the same category prompt
from Step 1 with the suffix: ‘The background extends
naturally from the existing scene.
Seamless transition
between regions, no visible boundaries. Consistent light-
ing and focus throughout the entire image.” The negative
prompt is identical to Step 1. Finally, we rerun Cerberus-
Det on the outpainted 512×512 image and accept the
sample only if the detector returns exactly one instance

D.
CNN architecture and training
Architecture.
All CNN models were based on
an ImageNet-pretrained ResNet-50.
We removed the
original classification head and used the final 2048-
dimensional feature layer as the shared representation.
On top of this feature layer we attached either one or
a combination of the following heads: a linear classifi-
cation head for object category (265 classes) and four
linear regression heads predicting the bounding-box pa-
rameters (Ch, Cv, Lh, Lv).
These heads were randomly
initialized with Xavier-uniform weights and zero biases.
We trained four variants of this architecture. Network
C included only the classification head. Network R in-
cluded only the four regression heads. Network CR in-
cluded both the classification head and the four regres-
sion heads. Network CRloc had the same backbone and
classification head as CR, but replaced each category-
independent regression head with a category-specific one:
each bounding-box head produced one output per class,
and during training the output corresponding to the
ground-truth class was selected.
Training. Images were resized to 224 × 224 and nor-
malized with the standard ImageNet channel statistics.
Bounding-box coordinates were standardized using the
training-set mean and standard deviation before regres-
sion. Training used shuffled mini-batches from the train-
ing split (8000 images per category) and performance was
monitored on a held-out validation split (2000 images per
category). Models were trained with batch size 208 using
stochastic gradient descent (learning rate: 0.02; momen-
tum: 0.9; weight decay: 10−4; learning-rate schedule: co-
sine annealing over 40 epochs), Smooth L1 loss for each
regression coordinate, and cross-entropy loss for classifi-
cation. The total loss was the sum of the regression and
classification losses. In models without the classification
head or without regression heads, the corresponding loss
terms were simply omitted.
Models were trained until
performance on the validation set plateaued.

A.
Linear decoding performance in macaque recordings
We have applied the linear decoding framework presented in the main text to the publicly available dataset of
macaque recordings [34] studied in [20], as well as to an ImageNet-pretrained ResNet-50 CNN. We reproduce their
qualitative results (Fig. 9a): decoding performance of both category and category-independent features improves
along the visual hierarchy. However, we also find that absolute regression performance remains limited (Fig. 9b): in
macaque IT, as well as in the CNN for most features, root nMSE remains above 0.5, meaning that the root-mean-square
prediction error is still larger than half the across-image standard deviation of the decoded feature.
We note that this last point may be less apparent in the original presentation of [20], where regression performance
was reported using the Pearson correlation coefficient. Here we instead report
√
nMSE, which we find more directly
interpretable, as it measures the typical prediction error (root-mean-squared error) in units of the standard deviation of
the decoded feature. In particular, because Pearson correlation is a nonlinear function of nMSE, it tends to compress
even appreciable differences in nMSE into a narrow interval near 1. Indeed, for ordinary least-squares (no ridge)
evaluated on the training set, Pearson correlation is related to nMSE by Pears =
√
1 −nMSE. For ridge regression on
held-out data, this relation is only approximate but still useful as an intuition. We can see that Pearson correlation
compresses a broad range of
√
nMSE values into a narrow range near 1.
For example,
√
nMSE ∈[0, 0.5]—from
perfect prediction to errors on the order of half a standard deviation—maps to Pears ∈[0.87, 1], making differences in
regression accuracy harder to visualize and interpret.
Fig. 9b additionally reports regression performance using the Pearson correlation coefficient, alongside nMSE, to
facilitate a more direct comparison with [20]. The Pearson values we obtain are comparable to those reported in that
work (cf. Supplementary Fig. 3 and Supplementary Fig. 9 of [20]). This comparison is not exact, because the original
analysis was performed on the full private dataset, whereas we here use the publicly available subset. Relative to the
public dataset, the full dataset contained 320 additional images per category, as well as 98 additional IT units recorded
from a third macaque. Even so, the Pearson-based regression performance reported here remains of similar magnitude
to that reported in [20]. In particular, the IT Pearson values in [20] are still sufficiently below 1 to be consistent with
a root nMSE well above 0.5, matching the conclusions we draw here from the public data.
B.
Regression performance for network CRloc
Here we show that optimization for regression alone is sufficient to substantially reduce the local-global gap, even
in the absence of the additional constraint imposed by a shared readout across categories. Indeed, we show that ∆E
is largely reduced not only in network CR, which is optimized for category-independent regression and classification,
but also in a network that we term CRloc, which we optimized for category-specific regression and classification (Fig.
10a-b). In CRloc, category-specific regression is implemented by attaching multiple regression heads to the feature
layer—one for each category—rather than a single head shared across categories.
We observed that, in network
CRloc, ∆E is largely reduced compared to network C, down to values only slightly higher than network CR. The
same observation holds for the three sources of error Ec, Es, Eo (Fig. 10c), and the two factors contributing to Eo,
namely alignment a of the feature-encoding directions, and SNR (Fig. 10d).

D.
Across-layer trends do not depend on the layer-freezing training schedule
In training the CNNs, we found that gradually unfreezing the weights of the ResNet-50 layers through the epochs,
from the feature layer downstream to layer 1, yielded models with slightly better regression performance. In particular,
the models reported in the main text were trained by unfreezing a new layer each epoch, in sequence: the feature
layer, layer 4, and layer 3, while layers 2 and 1 were kept frozen throughout the training. Here in the SI, we show that
the trends across layers reported in the main text (cf. Fig. 7) are virtually unchanged when network CR is trained
end to end with all layers unfrozen from the very first epoch, rather than with the layer-unfreezing schedule described
above. We call this network CR*. Fig. 15 shows regression performance as a function of layer depth for networks
CR, C and CR*. We still observe the trends reported in the main text: a sharp rise in regression performance emerges
only from layer 4, as well as an appreciable distinction in regression performance between networks C and CR/CR*.

Effect of limited images per category on the estimation of the local-global gap
In the main text, we reported ∆E/Eloc for regression of bounding-box features from the neural representations
elicited by the image set used in [20, 34] to obtain macaque ventral-stream recordings (Fig. 8c). Specifically, we
showed results for the recorded units in IT and V4, as well as for networks C and CR subsampled to 168 units,
matching the number recorded in IT. Since all units are available in C and CR, one could in principle also study how
∆E/Eloc varies with the number N of subsampled units, mirroring the analysis performed in the main text on our
image dataset (Fig. 8b). However, this analysis is much less informative for the image set used in [20, 34], because
that dataset contains only 400 images per category. When N becomes comparable to, or larger than, 400, the local
regressors begin to overfit, artificially increasing the estimated local error Eloc and thereby underestimating the local–
global gap. This effect is clearly visible in Fig. 17: beyond sufficiently large N, the local error reverses its expected
downward trend and instead increases with N. As a consequence, the estimated local–global gap is progressively
underestimated and can even become negative. More generally, this analysis highlights an important requirement for
future experiments aiming to estimate the local–global error gap reliably: the number of images per category should
exceed the number of recorded units, so as to avoid this overfitting regime.

dataset.

does not depend explicitly on object category, except through the natural range of aspect ratios associated with
different categories (for example, cars tend to be more extended along the horizontal axis, whereas penguins tend to
be more extended along the vertical axis). This is reflected in the high uniformity across categories in the distributions
of maximum side length and center coordinates. By contrast, aspect ratio is much more category-dependent, both in
its within-category mean and in its within-category spread (standard deviation).
